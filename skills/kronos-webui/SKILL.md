# Kronos WebUI

基于用户 `E:\K线预测\Kronos-master\webui`，保留 app.py、原 HTML 页面和模型源码逐字节快照。使用 skill-creator 所需的封装目录结构；任务运行在独立工作副本，不把用户数据、权重或旧预测打包进技能。

## 操作系统与路径

在完整分发包中首次调用时，先读 [包内环境准备](references/package-environment.md)。由Agent检查并按实际任务准备依赖；用户无需双击任何启动器，已有环境不重复安装。

在 macOS 或迁移到其他电脑时，先读 [平台说明](references/platforms.md)。按当前系统解析 Python、工作目录和模型路径；文档中的 Windows 命令仅为示例。

## 能做什么

- 中文或英文界面，顶部可切换语言；按钮、参数、状态、表格和图表标题随之切换。
- 从本地 data 目录选择 CSV/Feather，显示行数、日期、周期和价格信息。
- 选择 mini/small/base、CPU/CUDA/MPS；通过本地映射可使用已下载的配套权重。
- 调节 temperature、top_p、sample_count。
- 原页面固定400根历史＋120根已有数据窗口，展示历史/预测/实际的 Plotly K 线与表格。
- 原程序将结果保存到工作副本 `webui/prediction_results/*.json`。

它主要是**历史窗口预测对比界面**。不把它说成现有 `kronos-kline-predict` 所有功能的图形界面；后者的1/5/15/30分钟未来交易日、盘中更新、准确率验证并未接进原页面。原网页无文件上传按钮，`add-data` 将用户已有文件复制到 data 后在页面选择。

用户只要预测或结果图时，默认使用预测skill并将图直接内嵌在对话，不为展示图而启动网页。只有明确请求WebUI时执行下面的启动和语言询问流程。若本WebUI任务产生预测结果，也将可读的图截图/导出图保存到任务目录，以 `![预测结果图](绝对路径.png)` 展示在对话，并附简短解读；先核对原图时间标签是否与真实目标一致，偏移时明确说明，不能当作精确交易日期。

## 使用流程

每次新建、启动或重新启动界面之前，先在当前对话询问：**“你需要中文界面，还是英文界面？”** 等待用户选择后再启动。若本次请求已明确指定语言，直接采用，不重复问；本次启动期间的故障重试或技术重启沿用已选语言。不把上一次使用语言当成新一次启动的默认答案。停止、查看状态和仅说明功能无需问语言。

1. 首次读取 [原界面行为](references/behavior.md)，尤其是时间显示、amount排除和模型加载限制。
2. 用 `scripts/webui.py stage --work-dir <新目录>` 创建源码副本。已有工作目录先 check，不重复 stage。
3. `add-data --work-dir ... --file <CSV或Feather>` 导入已有文件；至少520行，真实时间、有效OHLC、无缺值，元数据记录哈希。Feather需pyarrow。行情获取使用预测skill的权威来源核验流程，不编造行情。
4. `check` 验证依赖、源码和已导入数据。缺库时复用现有独立环境，按原 `webui/requirements.txt` 与根 requirements 安装；不要重复替换已适配的GPU PyTorch。
5. 按 [启动说明](references/usage.md) 执行 serve，中文显式传 `--language zh`，英文传 `--language en`；监听127.0.0.1，默认7070，关闭debug/reloader。打开链接包含 `/?lang=zh` 或 `/?lang=en`，使本次选择覆盖浏览器的旧语言Cookie。保持终端会话，在HTTP可访问后向用户给出链接；用户要求打开时用应用的浏览器面板。
6. 界面先加载数据再加载模型，确认 `/api/model-status` 返回 loaded=true 后预测。缺依赖/加载失败直接报告错误，不运行模拟预测。等待完成、核实结果JSON后解释图和实际限制。
7. 用户要求停止时，对该 serve 的终端会话发 Ctrl+C，再请求 status 确认服务已停止。若终端未转发中断，读取runtime.json，并核对PID的实际命令、工作目录和端口均属于本次serve后终止该进程。不要按端口强杀不明进程；PID记录可能过期。

## 约束

保留原app/template/模型文件快照；在HTTP展示层增加中英文翻译和语言切换，不改模型算法、数据数值、API字段名或原始结果文件。启动器设置运行目录、本地模型映射和服务选项，增加输入检查。语言切换会刷新页面，需重新加载页面的文件/模型状态，但不会删除结果。不会把固定间隔图表标签自动变成交易日历。默认单线程，推理时其他请求等待。

模型首次加载可能下载权重，页面图表和请求库还依赖外部 CDN。实际运行以本机状态为准，不因模型名字较大就承诺更准。不提供WebUI内的训练、自动下单、账户管理或多用户服务。

交付预测结果时，当前对话末尾附上：本次是依据清华大学开源的模型预测，不是确定的买卖，不要全盘相信，要有自己的判断。

封装验证范围见 [validation.md](references/validation.md)。
