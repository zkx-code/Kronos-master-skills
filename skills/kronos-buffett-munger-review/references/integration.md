# Kronos 证据支持度评分字段与口径

## 只读输入

| 输入 | 用途 |
| --- | --- |
| `run.json: status` | 确认推理是否完成；输入检查成功不等于预测完成 |
| `history_cutoff`, `forecast_start`, `forecast_end` | 固定预测时的信息边界和目标日期 |
| `input_csv`、`data-source.json` | 核对标的、来源、复权、单位、交易时区和历史覆盖 |
| `last_observed_close` | 作为预测前参照，计算预测路径相对起点的变化 |
| `parameters`, `model_id`, `device` | 确认周期、历史窗口、采样数和运行条件 |
| `forecast.csv`, `forecast_quality` | 核对预测 OHLC、量额和质量异常 |

涉及文件校验时，称为“数据完整性与口径一致性检查”，不要使用其他旧术语。

## 五项评分

| 项目 | 满分 | 必查内容 |
| --- | ---: | --- |
| 数据完整性与口径一致性 | 30 | 标的、周期、复权、单位、来源、预测起点、历史截止、数据完整性、信息边界 |
| 历史方向、幅度和基准比较 | 20 | 可见历史同周期收益、波动范围、历史分位数、简单不变收盘基准 |
| OHLC 与交易时间结构 | 20 | `low <= open <= high`、`low <= close <= high`、交易日、休市跳空、时间顺序 |
| 多次采样稳定性 | 20 | 方向一致性、价格离散程度、区间宽度、反转频率 |
| 表述校准 | 10 | 区间、不确定性、避免把点预测写成确定结果或概率 |

每项根据当前预测实际材料给分，五项相加为基础总分。历史趋势只支持合理性，不证明未来重复；多次采样均值不是上涨概率。

## 硬门槛计算

1. 数据完整性、口径一致性或时间边界无法确认：第一项 `<=10`，总分 `<=40`。
2. OHLC 基本关系错误：第三项 `0`，总分 `<=35`，必须写“存在结构错误”。
3. `sample_count=1`：第四项 `<=5`。
4. 精确价格没有区间、波动范围或不确定性说明：第五项 `<=2`。

多项同时触发时，先限各项，再取总分上限的最低值。硬门槛不能被其他项目高分抵消。

## 三段对话模板

```markdown
## 巴菲特式意见
- 判断：有一定依据 / 依据薄弱 / 存在明确问题 / 材料不足
- 数据、历史方向、幅度和简单基准的实际证据：
- 关键缺口：

## 芒格式意见
- 判断：未发现明显结构问题 / 有明显疑点 / 存在明确错误
- OHLC、交易时间、采样稳定性和失败路径：
- 触发的硬门槛：

## 综合判断
- 结论：有一定合理性 / 依据薄弱 / 存在明确错误 / 材料不足
- 证据支持度：X/100
- 五项评分：数据完整性与口径一致性 __/30；历史方向、幅度和基准比较 __/20；OHLC 与交易时间结构 __/20；多次采样稳定性 __/20；表述校准 __/10
- 硬门槛：未触发 / 已触发（说明项目与总分上限）
- 最值得相信的部分：
- 最值得怀疑的部分：
- 未经过目标行情事实验证。
```

只依据预测发生前可见材料填写模板。不得加入目标区间实际行情、MAE、RMSE、方向命中率、事后基准表现或预测概率。
